# Estate: gestión inmobiliaria en Odoo

Este módulo sirve para organizar y administrar propiedades inmobiliarias dentro de Odoo. Permite crear fichas de propiedades, clasificarlas por tipo y añadir etiquetas de colores para una mejor visualización.

## ¿Cómo instalar?

1. Copiar la carpeta "estate" en la carpeta de addons de tu Odoo.
2. Desde el menú de Apps, actualizar la lista de aplicaciones.
3. Buscar "Estate" e instalarlo normalmente.

## Configuración rápida

- Puedes crear y editar los tipos de propiedad desde su propio menu.
- Las etiquetas tambien se pueden personalizar y asignarles un color para distinguirlas fácilmente.

## ¿Para qué sirve?

- Crear propiedades nuevas y asignarles tipo y etiquetas.
- Registrar ofertas recibidas por propiedad y aceptarlas o rechazarlas.
- Registrar si la propiedad fue vendida, cancelada o se encuentra disponible.
- Ver las propiedades en una vista Kanban, agrupadas automáticamente por tipo.

## Detalles y personalizaciones

- La vista Kanban ya viene agrupada por tipo de propiedad.
- Se desactivó el arrastre de columnas y tarjetas usando las opciones que recomienda Odoo, pero en algunos casos puede seguir mostrándose.
- Los colores de las etiquetas usan la paleta estándar de Odoo.

## Cosas a tener en cuenta

- En algunos temas o versiones, el drag de tarjetas puede seguir funcionando aunque esté desactivado en la configuración.
- El color de cada etiqueta depende del número que se le asigne y de la paleta de Odoo.
- No se pueden borrar propiedades que ya estén vendidas o canceladas.
